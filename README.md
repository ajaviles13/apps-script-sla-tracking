# Apps Script SLA Tracking

Custom Google Apps Script for Service Level Agreement (SLA) tracking sheets and the report that consolidates them.

## Folders

### `SLA_Report_Generator`

Scripts for the Report Generator Google Sheet. They pull data from all four SLA Tracking Google Sheets and ingest it into the Report Generator Google Sheet.

### `SLA_Tracking_Google_Sheets/foundational_scripts`

Foundational scripts for the SLA Tracking Google Sheets. They connect to the Metadata Extraction and Custom Menu Option functions in those sheets.

### `SLA_Tracking_Google_Sheets/misc_scripts`

Miscellaneous scripts built ad hoc for the SLA Tracking Google Sheets. These are intended for single execution runs.
